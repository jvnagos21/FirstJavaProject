## 🖥️ Saída esperada

```

```

> 👀 **Repare:** o `System.out.print` **não** pula linha automaticamente. Por isso, só o `\n` da primeira mensagem quebra a linha, e as duas últimas saem coladas: `cute!Stan!`.

---

## 🧠 Entendendo o código

```java
public class Main {

    public static void main(String[] args) {

        // THIS IS MY FIRST JAVA PROJECT
        System.out.print("I like Twice!\n");
        System.out.print("They are really cute!");
        System.out.print("Stan!");
    }
}
```

- 🏛️ `public class Main` → declara a classe principal do programa
- 🚪 `public static void main(String[] args)` → ponto de entrada, onde tudo começa
- 🖨️ `System.out.print(...)` → imprime texto no console, sem quebra de linha
- ↩️ `\n` → caractere especial que pula para a próxima linha
